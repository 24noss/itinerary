Day 1

10/10(土)　上高地と山の宿

  1. 08:30

    名古屋 集合 → 車2台で出発

    名古屋から東海北陸道 → 飛騨清見IC → 中部縦貫道 高山IC → 国道158号で平湯の「あかんだな駐車場」へ（約3時間の目安）。

    2台が別々になりにくいよう、途中の合流ポイントとしてひるがの高原SAでの休憩を提案します。
    名古屋駅 → あかんだな駐車場
  2. 〜12:00

    あかんだな駐車場に到着 → シャトルバスで上高地へ

    上高地はマイカー規制があり、車では入れません。駐車場に車を置いて濃飛バスのシャトルで向かいます。
    • 所要 約30分、片道 1,400円/人（2025年9月時点の情報）
    • 予約不可。10月は紅葉シーズンで混雑します
    • 最終便の時刻：当日要確認
  3. 12:30〜15:30

    上高地を散策

    河童橋（穂高連峰の眺め）・昼食・大正池・梓川沿いの散歩。

    10月の上高地は朝晩5℃前後まで冷え込みます。防寒を忘れずに。
  4. 15:30〜16:00

    帰りのバス → あかんだな駐車場

    最終便の時刻は当日要確認。余裕を持って乗り場へ。

  5. 移動の途中

    高山市内で BBQ の食材を買い出し

    高山市のスーパーを探す
  6. 夕方

    宿にチェックイン → BBQ・焚き火・サウナ

    チェックインの受付は宿ではなく「飛騨高山ゴルフ練習場ワット」です。詳しくは下の宿セクションへ。
    あかんだな → 宿

Day 2

    13:30 までに到着必須
    宿 → アドニスゴルフクラブ
  3. 13:30

    到着・受付

  4. 13:50

    スタートホールに集合

    スタートの10分前には到着が必須です。

    キックオフ

服装・持ち物

  • スポーツシューズ（サッカースパイクは不可）
  • ゴルフに準じた服装、またはサッカー用のウェアで OK
  • ポロシャツ＋スポーツ用インナー、ハーフパンツ＋スポーツタイツの組み合わせも可
  • 寒いときは防寒着 OK
  • 来場時のジーパン・サンダルは禁止
  • サッカーボールはできるだけ持参

ルール・マナー

  • グリーン上でのプレーは原則禁止
  • 大声や他のプレーヤーへの迷惑行為は禁止
  • クラブハウス内・スタート室前・駐車場ではボールを使わない
  • 喫煙はティーグラウンドのみ
  • スタッフの指示に従う（従わない場合は退場あり）
  • マナーの悪い人は入場を断られます

キャンセル・中止

  • 当日のキャンセルや来場しなかった場合は、プレーフィと同額のキャンセル料
  • 悪天候などで予告なく中止になることがあります
